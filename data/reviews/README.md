# NetSage AI Human Review System

This directory contains the human-in-the-loop review data. The system allows an instructor or senior network engineer to review AI-generated troubleshooting advice before it is applied to the network.

## Files
- `reviews.csv`: Stores the raw review decisions (`Accepted`, `Edited`, `Rejected`) and any corrections.
- `responsible_ai_log.csv`: Tracks AI correctness, safety notes, and alignment for audit purposes.
