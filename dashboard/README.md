# NetSage AI Dashboard

This is the frontend dashboard for the NetSage AI Troubleshooting tool, built using Streamlit.

## Features
- **Overview Metrics:** Total cases, issue types, severity breakdowns, and human review decisions.
- **Workflow Demonstration:** Displays the Responsible AI log and cases that required human intervention.
- **Case Detail Explorer:** An interactive view to inspect symptoms, raw Cisco device output, the AI diagnosis, and the final human-in-the-loop decision for any of the 30 troubleshooting scenarios.

## How to Run
```bash
streamlit run app.py
```
